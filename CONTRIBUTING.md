# Contribuer — corriger une fiche

Une correction = une **issue** ou une **pull request** sur une fiche (`data/fiches/<uid>.yml`), ou un message via la page
[Droit de réponse](https://libres.actitude.org/droit-de-reponse/) du site.

Ce qui est accepté : un fait daté avec sa **source citée** (document, article, témoignage identifié), une erreur de
classification argumentée au regard du cadre (`docs/cadre.md`), un cas nouveau qui passe les cinq portes du cadre.
Ce qui ne l'est pas : une appréciation sans source, une réécriture du cadre hors décision explicite.

Délai de réponse : **un mois**. Toute contribution acceptée est publiée sous les licences du dépôt (`LICENSE`) ;
les contributeurs sont nommés dans la fiche (`sources:`) s'ils le souhaitent.
