# Charte visuelle — libres.actitude.org

Famille actitude, canal igor (niveau 2). Proposée le 2026-09-30, **à valider par @graphiste**.
- Tokens : `assets/style.css` (`:root`, sombre via `prefers-color-scheme` et `[data-theme]`).
- Fond papier `#F5F2E9`, encre `#22201B`, accent brique `#9A3E23` (canal igor), ocre `#B9832E`, vert forêt `#1C4A32` (réservé au corpus).
- Motif signature : **l'empreinte des cinq portes** — cinq cases dans l'ordre P1→P5 ; franchie = plein, partielle = demi diagonale, non franchie = contour barré, non établie = pointillé. Jamais la couleur seule.
- Statuts : corpus (vert forêt), corpus sous condition (brique, filet double), seuil (ocre), épreuve (gris).
- Polices auto-hébergées (copiées de communautes) : Source Serif 4, IBM Plex Sans/Mono.
- Carte : départements IGN simplifiés, projection équirectangulaire corrigée (cos 46,5°), aucune tuile externe.
- À éviter : dégradés décoratifs, cartes arrondies à ombre, emoji, information portée par la seule couleur.
